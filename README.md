# GPO Fishing Macro

Macro de pesca para Grand Piece Online (Roblox), desenvolvido por [ikeuchz](https://github.com/ikeuchz).

## Download

Baixe o arquivo [GPO-Fishing-Macro.exe](./GPO-Fishing-Macro.exe) e execute no Windows 64 bits.

## Como usar

1. Abra o Grand Piece Online e o macro.
2. Configure a área do minigame de pesca e as teclas dos seus itens.
3. Pressione **F1** para iniciar ou parar.

| Atalho padrão | Ação |
| --- | --- |
| F1 | Iniciar ou parar o macro |
| F2 | Selecionar e salvar a área de pesca |
| F3 | Encerrar o aplicativo |

Os atalhos podem ser alterados na interface. As configurações são salvas automaticamente.

## Recursos

- Pesca automática com área configurável.
- Ajustes de teclas, cores e tempos de espera.
- Compra automática de iscas.
- Seleção automática de iscas.
- Armazenamento automático de frutas.
